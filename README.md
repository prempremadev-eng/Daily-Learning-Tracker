# 📚 Daily Learning Tracker

A small full-stack app to log what I learn every day.
**Frontend:** React + Vite · **Backend:** Zoho Catalyst (Functions + Data Store), with no separate Express server.

🔗 **Live (Development):** https://daily-learning-tracker-60072483450.development.catalystserverless.in/app/index.html

---

## Features

- Add a learning record (date, topic, description, status)
- Edit and delete records
- Filter by status: All / In Progress / Completed
- Latest records shown first
- Loading states and error messages

## Tech stack

| Part | Tool | Why |
|---|---|---|
| UI | React 19 + Vite | Fast dev server, simple components |
| API | Catalyst **Advanced I/O Function** (Node.js 20) | Serverless backend with full control of HTTP methods (GET/POST/PUT/DELETE) |
| Database | Catalyst **Data Store** | Managed table, no DB server to run |
| Hosting | Catalyst **Web Client** | React and the API share one domain, so production needs no CORS setup |
| Config | Function **env variables** | Table name is not hard-coded |

## Data Store table: `LearningRecords`

| Column | Type | Notes |
|---|---|---|
| `ROWID` | auto | Used as `id` |
| `learning_date` | date | Sent to React as `date` (`date` is a SQL keyword, so the column has a different name) |
| `topic` | varchar(255) | Required |
| `description` | text | Optional |
| `status` | varchar(20) | `Completed` or `In Progress` |
| `CREATEDTIME` | auto | Breaks ties when sorting |

## API

Base URL: `/server/learning_records`

| Method | Path | Body | Action |
|---|---|---|---|
| GET | `/` | – | Get all records (latest first) |
| POST | `/` | `{ date, topic, description, status }` | Add a record |
| PUT | `/:id` | `{ date, topic, description, status }` | Update a record |
| DELETE | `/:id` | – | Delete a record |

Every response is JSON: `{ "data": ... }` on success, or `{ "error": "message" }` with a 400/404/500 status.

## Run locally

Requirements: Node.js 20+ and the Catalyst CLI (`npm i -g zcatalyst-cli`), logged in with `catalyst login`.

```bash
# Terminal 1: backend
cd Daily-Learning-Tracker
catalyst serve                  # http://localhost:3000/server/learning_records/

# Terminal 2: frontend
cd Daily-Learning-Tracker/frontend
npm install                     # first time only
npm run dev                     # http://localhost:5173
```

Vite proxies `/server/*` to `localhost:3000`, so the browser sees one origin and there are no CORS errors.
Data Store calls from `catalyst serve` go to the **Development** environment.

## Deploy to Catalyst

```bash
cd Daily-Learning-Tracker/frontend
npm run build                   # builds React into ../client
cd ..
catalyst deploy                 # deploys the function and the web client
```

## Notes

- **CORS:** in production, React and the API are on the same Catalyst domain. `localhost:5173` is added under Authorized Domains for local testing.
- **`base: './'`** in `vite.config.js` is needed because Catalyst serves the web client under `/app/`.
- **Secrets:** the frontend has no keys. `VITE_API_BASE` (see `frontend/.env.example`) is only needed if the frontend is hosted on a different domain.
- **Auth:** the API is public for now. Next step: add Catalyst Authentication.
